# Зона 0672

Зона 0672 — нерезидентная программа переписи данных на диске 2053. Резидент её не вызывает. Слово `БАЙКАЛ` в ней — константа, с которой сравнивается последнее слово зоны-эталона.

В каталоге это прямо так и названо (`rukava.be:2124`). В текстах СВС зоны 0672 нет. В работающем образе `sbor2053.bin` логическая зона 0672 лежит как физическая 0676 (сдвиг +4, как у конфигурации 0750→0754). Код грузится с адреса 04000: почти все переходы смотрят в диапазон 04000–04617.

## Что делает программа

Обмен с диском идёт командами `УВВ`, буфер зоны — 70000–71777. Тексты диагностики собраны с 04771, разделитель полей — код 0374:

| Адрес | Текст |
|---|---|
| 04771 | НЕТ ГОТОВН.ДИСКА |
| 04776 | ОШИБКА КОНТ.СУММЫ |
| 05001 | АВАРИЯ--АВАРИЯ |
| 05006 | ОШИБКА БУФЕРА КМД |
| 05011 | НЕТ КЛЮЧГ…МД |
| 05016 | НЕТ.ОБМЕНА |
| 05020 | НЕТ МД УПРЯТЫВАНИЯ |
| 05024 | НЕТ Д ВВОДА |
| 05026 | ЗАМЕНИ ТРАКТ N=… МБ-20 |
| 05032 | ТЕСТЫ ПЕРЕПИСАНЫ НА МБ |
| 05036 | НЕ ТА ИНФ. В ЗОНЕ ЭТАЛ. СУММ. |
| 05043 | НЕТ ИНФ. ПО МД ТЕСТОВ |
| 05047 | НЕТ МД С ТЕСТАМИ |

По этим текстам программа проверяет готовность диска и контрольные суммы, копирует тесты на МБ и сверяет зону с эталоном. Успешный проход печати «ТЕСТЫ ПЕРЕПИСАНЫ НА МБ» заканчивается `стоп` (04401). Другая ветка затирает нулями последние 31 слово буфера (71741–71777) и передаёт управление на 70000 — на только что прочитанную зону.

## Куда ставится БАЙКАЛ

Константа стоит в самой программе, слово 04621:

```
04460  сч  04621        ; БАЙКАЛ
       нтж 71777        ; последнее слово прочитанной зоны
04461  пе  04456        ; не совпало
```

71777 — это слово 1023 буфера 70000, то есть последнее слово зоны. Совпало — эталон принят, дальше сверяются четыре слова зоны (71600–71603) со словом 71400. Не совпало — печать «НЕ ТА ИНФ. В ЗОНЕ ЭТАЛ. СУММ.» (05036) и повтор. Та же печать, если слово 01033 после обмена не все единицы (04626, проверка на 04454).

Программа это слово только читает. Записи `БАЙКАЛ` в зону в ней нет.

Номер зоны берётся из ячейки 00002, она вне этого модуля:

```
04451  сч  00002
       сда 64+3
04452  и   04622        ; разряды 25–36
       слц 04627
04453  зп  72000
       пв  04062        ; сам обмен
```

04622 — маска `0000777700000000`. На эту ветку попадают с 04245, если `(00002) ∧ (00300)` не нуль. Чем заполнены 00002 и 00300, в зоне 0672 не видно.

Вход в проверку эталона — не единственный режим. С 04000 программа сначала разбирает слово 01050 и ячейки 00002/00003 и только при одном сочетании идёт на 04450.
