# Э62 '115': одна команда остановленной подчинённой задачи

Главная задача вызывает Э62 '115', и её подчинённая задача (ПЗ) выполняет одну команду, после чего снова останавливается с причиной 0140. Аппаратного пошагового режима для этого нет. ОС вызывает искусственное внешнее прерывание: перед пуском ПЗ взводит 30-й разряд ГРП («имитация»), и машина прерывается при первой возможности.

## Путь вызова

1. **РЕСУРС → ЭКГДР.** РЕСУРС через `ЭКГД` передаёт Э62 в ЭКГДР. Номер функции берётся из исполнительного адреса, `ИПЗ+36 & 077777`. Функции больше `ЧЭК` = 0136 отвергаются через `КП25` (`ekgdr.be:14–16`).
2. **Проверка ПЗ.** Для функций 040–0117 ЭКГДР смотрит слово `ШКАЛА` (`ekgdr.be:23`, `1854`). Для 0115 разряд взведён, поэтому вызывается `ЕСПОД` (`ekgdr.be:160`). Он ищет ПЗ по СМ главной:
   - СМ < 0100 — это номер задачи. Она должна быть подчинённой этой главной (`ПОДЧ`), либо подходить по архиву или по группам;
   - СМ ≥ 0100 — это шифр, ищется подчинённая с таким `ШИФРМ`;
   - найденная ПЗ даёт М11 = её номер, М12 = её ИПЗ;
   - если ПЗ не найдена, главная получает СМ = 0.
3. **КАНАЛ.** Функции от 060 и выше уходят в КАНАЛ: `МОД 36(М10); ПБ З-48`. Для 0115 в таблице стоит `СЧИ М11; ПБ А115` (`kanal.be:843`).

## `А115` (`kanal.be:1463`)

```
ЭКО   := М11                номер ПЗ, которую надо прошагать
ЭКО+1 := 0
ИПЗ+36 &= Е41П1             стирается причина останова ПЗ (разряды 48–42)
МШГП  |= ОСПОД & бит(М11)   ПЗ переходит из «остановленных подчинённых»
ОСПОД &= ~бит(М11)          в очередь на пуск
```

Главной возвращается «хорошо».

## Пуск ПЗ: `ЕСЭ`

`БВЗ` перед `КИК` проверяет `ЭКО` (`disp70.be:1812`). Если оно не 0, управление идёт на `ЕСЭ` (`khlam.be:873`):
- если `ЭКО & 0377` не равно `НЗАД`, то есть пускается другая задача, всё идёт как обычно, через `КИК`;
- если пускается сама ПЗ:
  - `ЭКО+1 := Е6`;
  - `увв '31'` с СМ = Е6. По SIMH `увв 031` взводит в ГРП разряды СМ, сдвинутые на 24 (`besm6_cpu.c:662`). Получается 30-й разряд ГРП, «имитация»;
  - затем `КИК` → `КИК1` → `ВЫПР (М3)`.

## Останов после шага: `ПРОГПР`

ГРП 30 приходит в `ПРОГПР` (`khlam.be:848`) через `ИМИТАЦ` в БОЭК1 (`boek1.be:2817`).

- Если `ЭКО+1` = 0, это не шаг, и идёт обычная обработка (`пир`).
- Иначе:
  - М15 := номер ПЗ, М16 := её ИПЗ;
  - `ЭКО` и `ЭКО+1` обнуляются;
  - если `ш+1` ≠ 0, ГРП 30 взводится заново. Этот разряд делит с шагом ещё одна программа (`ш` — ячейка МОТТ), и её прерывание нельзя потерять;
  - если в ИПЗ+36 уже есть причина (команда сама вызвала авост), шаговая причина не ставится: управление уходит на `БМВ`;
  - иначе ИПЗ+36 |= `Е48Е47`, то есть причина = **0140**. Затем `БПУ` (сохранение контекста) и `ЗАПВЕТ` (`disp70.be:2261`): задача снова остановлена, главная получает событие. По комментарию в dispak это событие 9.

`ПРОГПР` не идёт через `ТВ201`. Правка М33 по Е10 здесь не нужна: внешнее прерывание приходит до выборки очередной команды.

## Закрытый лист во время шага: `хм`

В обработке 20-го разряда ГРП (закрыт лист по выборке числа, `khlam.be:1187`) есть проверка:
- если 30-й разряд ГРП висит и шагается текущая задача (`ЭКО` = `НЗАД`), то `ЭКО+1 := 0` и разряд гасится (`рег '37'`);
- `ЭКО` остаётся. Когда лист подкачают и ПЗ пустят снова, `ЕСЭ` опять взведёт шаг, и команда выполнится заново, уже целиком.

## Левая и правая команды

Внешнее прерывание на БЭСМ-6 берётся только на границе слова, то есть перед левой командой. ОС решает только, в какой задаче взвести ГРП 30. Как далеко пройдёт задача, зависит от машины.

**Пуск с правой команды (ПрК = 1).** Задача выполняет правую команду, следующая выборка — левая команда слова М33+1, прерывание берётся. Шаг равен ровно одной команде.

**Пуск с левой команды (ПрК = 0).** Внутри слова прерывание взять нельзя:

| Левая команда | Что выполнится до прерывания |
|---|---|
| обычная | левая и правая команды слова; шаг из двух команд |
| переход, который сработал (`пб`, `пв`, `по`/`пе` с переходом, `цикл`…) | только она: переход ведёт на левую половину нового слова, это граница |
| переход, который не сработал | обе команды |
| `мод`/`мода` | обе: С кончает действовать на правой команде того же слова |
| экстракод | экстракод целиком, возврат на левую команду следующего слова; см. ниже |

**Где оказывается задача после шага.** ПрК = 0, М33 указывает на очередное слово (или на цель перехода). Если правая команда была `мод`/`мода`, С сохраняется в М20 с ПрИК(РК).

**Пройти только левую команду через Э62 '115' нельзя.** Из левой половины шаг всегда доходит до границы слова.

**Экстракод.** Экстракод работает в супервизоре с БлПр. Выход идёт через `ЭКВЫХ`/`БВЗ`, а `ЭКО` ещё не обнулён, поэтому `ЕСЭ` взведёт ГРП 30 повторно, и это безвредно. Вся схема держится на том, что машина после `ВЫПР` успевает выполнить хотя бы начатое слово, прежде чем принять висящее внешнее прерывание. Иначе шаг из левой половины ничего бы не продвигал. Точной аппаратной логики найти не удалось.

## Особенности

- **`ЭКО` — одна ячейка на всю систему.** Одновременно может шагать только одна ПЗ. Второй вызов Э62 '115' от любой главной перезапишет первый.
- **`А115` не проверяет, что ПЗ остановлена.** Если ПЗ работает, `ЭКО` всё равно взводится, и при её следующем пуске она выполнит шаг и встанет с причиной 0140.

## Эмуляторы

- **SIMH** (`besm6_cpu.c:1983`). Внешнее прерывание проверяется перед каждой командой, если не взведён `RUU_RIGHT_INSTR` и нет БлПр. `ВЫПР` снимает БлПр из SPSW (`besm6_cpu.c:1652`). Поэтому:
  - при пуске с левой команды прерывание берётся сразу, до первой команды, и шаг ничего не выполняет;
  - при пуске с правой выполняется одна правая команда.

  Поведение «после `ВЫПР` слово выполняется», на которое рассчитан `ЕСЭ`, SIMH не воспроизводит.
- **dispak** (`dispak/extra.c`, `case 0115`; `tasks.c:531`).
  - Механизм свой (`pz->step`), ГРП 30 не моделируется.
  - Флаг проверяется в `task_poll` на каждой команде, а не на границе слова, так что разницы между левой и правой половиной нет.
  - На работающую или завершённую ПЗ он отвечает кодом 3, тогда как ОС `ЭКО` взводит.
  - Шаг кончается после каждой команды, а не на границе слова. Проверено прогоном `ШАГ` СЛУГИ 2148:
    - с правой половины один вызов выполняет одну команду, как на машине;
    - с левой половины первый вызов выполняет только левую команду и оставляет ПЗ перед правой, второй — правую.

    СЛУГА это переносит: она подменяет правую половину на `мода 0` и повторяет Э62 '115' (до 100 раз), пока М33 не уйдёт со слова.

## Как пользуется СЛУГА

`ШАГ` СЛУГИ 2148 вызывает Э62 '115' из подпрограммы G17357. Перед шагом с левой половины она подменяет слово на «левая команда / `мода 0`». Если после шага в М27 взведён ПрИК(РК), то выполнилась и `мода 0`, значит, левая команда не была переходом. Тогда СЛУГА сама ставит М33 на то же слово и ПрК = 1. Подробнее — в `MANUAL.md` проекта re-sluga, раздел 8.2.
